# Lab 2: ALU Transcript Generator

## Overview
This repository contains a Python application and a Bash script designed to process student course grades, perform academic evaluation, and organize course data files.

## Files Included
- `grades.csv`: Data file containing assignment names, category groups, scores, and weights.
- `grade-evaluator.py`: Python script that validates grade constraints, calculates total grades and GPAs, determines pass/fail status, and identifies eligible resubmissions.
- `organizer.sh`: Bash shell script that automates archiving `grades.csv` with a timestamp, resets the workspace, and logs operations.
- `Readme.md`: Documentation for the project.
